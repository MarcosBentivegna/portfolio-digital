# portfolio-digital

Portfolio personal de **Marcos Bentivegna** — Full Stack Developer y fundador de [Owtli](https://github.com/MarcosBentivegna).

Sitio estático con estética **neobrutalista** (azul y naranja), una sola página con secciones de experiencia, proyectos, skills y contacto.

## Vista previa

Abre `index.html` en el navegador o sirve la carpeta con un servidor local:

```bash
python3 -m http.server 5173
```

Luego visita `http://localhost:5173`

## Estructura

```
├── index.html          # Página principal (HTML + CSS + JS vanilla, sin dependencias)
├── uploads/            # Imágenes originales y CV
│   └── opt/            # Versiones optimizadas que usa la web
└── screenshots/        # Capturas de referencia
```

## Stack

- HTML semántico + CSS con tokens (tema claro/oscuro) + JS vanilla
- i18n ES/EN sin dependencias
- Google Fonts: Syne, Space Grotesk, JetBrains Mono
